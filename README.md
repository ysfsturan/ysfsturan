## Featured projects

### [Kastamonu UBYS Bot](https://github.com/ysfsturan/Kastamonu_UBYS_Bot) · `Active`

University-wide automated Telegram assistant for Kastamonu University students across all faculties, vocational schools (MYO), and institutes. Tracks ÜBYS exam grades and class rankings, calculates required finals and YANO/GANO honor-status projections, fetches Bologna Catalog hours for day-based attendance limits, resolves active electives in transcripts, discovers faculty announcements & exam PDFs, and delivers daily campus dining menus, Kuzeykent weather, weekly class schedules, academic calendar reminders, and interactive `/` commands.

**Stack:** Python · httpx · BeautifulSoup4 · Telegram Bot API · GitHub Actions · GitHub Gist API · Docker

### [Daily Horoscope Bot](https://github.com/ysfsturan/Daily_Horoscope_Bot) · `Active`

Automated astrology assistant powered by real astronomical calculations via pure-Python `astronomy-engine` (natal charts, houses, live planetary transits, aspect orbs, retrogrades, moon phases, eclipses, and compatibility) combined with auto-discovered Google Gemini Flash models and interactive Telegram `/` commands running on GitHub Actions.

**Stack:** Python · astronomy-engine · Google Gemini API · Telegram Bot API · GitHub Actions

### [Fortune Teller Bot](https://github.com/ysfsturan/Fortune_Teller_Bot) · `Active`

Multimodal AI Telegram bot supporting Turkish coffee cup photo interpretation (Gemini Vision), 3-card Major Arcana Tarot spreads, deterministic daily cards, 12-sign inline zodiac menus, Yes/No oracle guidance, dream interpretation, and conversational memory — deployable 24/7 via Render Web Service (`/webhook` + `/health`) or serverless GitHub Actions.

**Stack:** Python · Google Gemini API (Flash & Vision) · Telegram Bot API · Render Webhook · GitHub Actions · Docker

### [Classic Okey](https://github.com/ysfsturan/Classic_Okey) · `Active`

Web-based classic Turkish Okey game featuring AI opponents, a 2-tier wooden rack (*ıstaka*), drag-and-drop tile organization, and procedural Web Audio API sound effects.

**Stack:** JavaScript · HTML5 · CSS3 · Web Audio API

### [Classic Backgammon](https://github.com/ysfsturan/Classic_Backgammon) · `Active`

Browser-based classic Backgammon (*Tavla*) web application with AI opponent, local 2-player mode, legal-move highlighting, and Web Audio API sound effects.

**Stack:** JavaScript · HTML5 · CSS3 · Web Audio API
